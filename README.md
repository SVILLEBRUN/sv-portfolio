## Description
A modern, responsive developer portfolio built to showcase my skills, experience, and personal projects.

It is developed with Nuxt.js and TypeScript, styled with Tailwind CSS, and includes smooth animations powered by Framer Motion. The site is fully internationalized with i18n support for English, French, and Spanish.

This project reflects my approach to building clean, performant, and user-friendly web experiences, while providing a central place to explore the projects I have created over the years.


## Setup

Make sure to install dependencies:

```bash
npm install
```

## Development Server

Start the development server on `http://localhost:3000`:

```bash
npm run dev
```

Or on Mac OS, when getting an EINVAL error code try :
```bash
TMPDIR=/tmp npm run dev
```

## Production

Build the application for production:

```bash
npm run build
```

Locally preview production build:

```bash
npm run preview
```
